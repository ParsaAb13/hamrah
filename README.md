همراه (Hamrah) یک رابط کاربری تحت وب، فارسی و راست‌چین برای گفتگو با مدل‌های زبانی محلی است که از طریق [Ollama](https://ollama.com/) اجرا می‌شوند.

این پروژه با هدف ساده‌تر کردن دسترسی به مدل‌های زبانی طراحی شده است؛ به‌گونه‌ای که کاربران بتوانند بدون نیاز به استفاده از ترمینال یا نصب یک نرم‌افزار دسکتاپ سنگین، در محیطی ساده و آشنا با مدل‌های محلی تعامل داشته باشند.

همراه تلاش می‌کند میان سادگی، کارایی و استقلال از سرویس‌های ابری تعادل برقرار کند.

> **وضعیت پروژه:** نسخه 1.0.0 منتشر شده است.

---

## 1. چرا همراه؟

مدل‌های زبانی به بخش مهمی از ابزارهای روزمره برای یادگیری، برنامه‌نویسی، نوشتن و ایده‌پردازی تبدیل شده‌اند. بااین‌حال، استفاده از بسیاری از این ابزارها به سرویس‌های آنلاین و دسترسی مداوم به اینترنت وابسته است.

Ollama امکان اجرای مدل‌های زبانی روی دستگاه شخصی را فراهم می‌کند، اما تعامل با آن معمولاً به رابطی جداگانه نیاز دارد.

همراه با هدف ساده‌تر کردن همین فرایند ساخته شده است.

با استفاده از همراه می‌توانید:
- با مدل‌های زبانی نصب‌شده روی دستگاه خود گفتگو کنید.
- مکالمات خود را مدیریت و جست‌وجو کنید.
- پاسخ‌های متنی و کدهای برنامه‌نویسی را در محیطی مناسب مشاهده کنید.
- تنظیمات مدل و اتصال را از طریق رابط کاربری تغییر دهید.
- بدون وابستگی پیش‌فرض به سرویس‌های ابری هوش مصنوعی از مدل‌های محلی استفاده کنید.

**نکته:** همراه خودش یک مدل زبانی نیست و وظیفه دانلود، میزبانی یا اجرای مدل‌ها را بر عهده ندارد. این برنامه رابطی برای ارتباط با Ollama است. برای استفاده بدون اینترنت، Ollama و مدل موردنظر باید از قبل نصب و دانلود شده باشند.

## 2. امکانات اصلی

### رابط کاربری و تجربه استفاده
- طراحی فارسی و راست‌چین (RTL)
- رابط کاربری تاریک با طراحی مینیمال
- طراحی واکنش‌گرا برای نمایشگرهای مختلف
- امکان استفاده از فضای عریض‌تر در نمایشگرهای بزرگ
- مدیریت جهت نوشتار فارسی و انگلیسی (RTL/LTR)

### گفتگو و مدیریت پیام‌ها
- ایجاد و مدیریت چندین گفتگو
- ذخیره خودکار تاریخچه
- ویرایش پیام‌های ارسال‌شده و ارسال مجدد آن‌ها
- تولید دوباره پاسخ مدل
- ادامه پاسخ‌های نیمه‌تمام
- امکان توقف تولید پاسخ
- نمایش تدریجی پاسخ‌ها (Streaming)
- کپی محتوای پیام‌ها

### مدیریت تاریخچه
- جست‌وجو در عنوان و محتوای گفتگوها
- سنجاق کردن گفتگوهای مهم
- تغییر نام گفتگوها
- حذف گفتگوها
- دسته‌بندی گفتگوها بر اساس زمان:
  - سنجاق‌شده
  - امروز
  - دیروز
  - هفت روز اخیر
  - قدیمی‌تر

### نمایش محتوا و کدهای برنامه‌نویسی
- پشتیبانی از Markdown
- نمایش جدول‌ها و فهرست‌های تو در تو
- نمایش بلوک‌های کد
- هایلایت نحوی کدها (Syntax Highlighting)
- پشتیبانی از چندین زبان برنامه‌نویسی
- امکان کپی مستقیم کدها
- نمایش بخش تفکر مدل، در صورت ارائه توسط مدل

### ارتباط و مدیریت Ollama
- شناسایی مدل‌های نصب‌شده
- انتخاب مدل از طریق رابط کاربری
- نمایش وضعیت اتصال به Ollama
- نمایش نسخه Ollama
- نمایش تعداد مدل‌های نصب‌شده
- نمایش اطلاعات مدل انتخاب‌شده، شامل حجم، خانواده و سطح کوانتیزه‌سازی
- بررسی وضعیت حضور مدل در حافظه
- نمایش سرعت آخرین تولید پاسخ بر اساس توکن در ثانیه
- امکان بررسی مجدد وضعیت اتصال

### تنظیمات
- تغییر آدرس سرویس Ollama
- تنظیم دستور سیستمی (System Prompt)
- ذخیره تنظیمات کاربر
- بازگردانی تنظیمات پیش‌فرض
- پاک کردن تاریخچه گفتگوها

## 3. مسیر توسعه: از نسخه 0.1 تا 1.0

همراه در ابتدا به‌عنوان یک رابط ساده برای ارتباط با مدل‌های زبانی محلی توسعه پیدا کرد. در نسخه‌های بعدی، تمرکز توسعه از ایجاد یک محیط گفتگوی اولیه به بهبود تجربه کاربری و اضافه کردن ابزارهای مدیریتی و فنی تغییر کرد.

| بخش | نسخه 0.1.0 | نسخه 1.0.0 |
|---|---|---|
| رابط کاربری | رابط اولیه فارسی | طراحی و تجربه کاربری بهبودیافته |
| ارتباط با Ollama | اتصال و انتخاب مدل | نمایش جزئیات اتصال و مدل |
| گفتگو | ارسال و دریافت پیام | ویرایش، ارسال مجدد، تولید دوباره و ادامه پاسخ |
| تاریخچه | ذخیره گفتگوها | جست‌وجو، سنجاق، تغییر نام و دسته‌بندی |
| نمایش محتوا | نمایش متن و کد | Markdown پیشرفته‌تر و هایلایت کد |
| تنظیمات | آدرس Ollama و System Prompt | تنظیمات تکمیل‌شده و حالت نمایش عریض |
| نمایشگرها | طراحی واکنش‌گرا | بهبود تجربه در نمایشگرهای کوچک و بزرگ |
| ذخیره‌سازی | LocalStorage | مدیریت بهتر حافظه و حفظ گفتگوهای قبلی |

### مهم‌ترین تغییرات نسخه 1.0.0

**مدیریت پیشرفته‌تر گفتگوها**

امکان جست‌وجو، سنجاق کردن، تغییر نام و دسته‌بندی گفتگوها اضافه شد تا مدیریت مکالمات طولانی ساده‌تر باشد.

**کنترل بیشتر روی پیام‌ها**

کاربران می‌توانند پیام‌های قبلی را ویرایش کنند، پاسخ مدل را دوباره تولید کنند یا تولید پاسخ نیمه‌تمام را ادامه دهند.

**نمایش بهتر محتوای فنی**

پشتیبانی از Markdown، جدول‌ها، فهرست‌های تو در تو و هایلایت کدها توسعه پیدا کرد. هایلایت کد نیز بدون وابستگی به کتابخانه خارجی پیاده‌سازی شده است.

**اطلاعات دقیق‌تر درباره مدل**

اطلاعات بیشتری از وضعیت اتصال، مدل انتخاب‌شده و وضعیت اجرای آن در اختیار کاربر قرار می‌گیرد.

**بهبود مدیریت داده‌ها**

ذخیره‌سازی گفتگوها بهبود یافته و در صورت پر شدن حافظه
