# hamrah | همراه

**A lightweight, Persian-first web interface for local language models running through [Ollama](https://ollama.com/).**

همراه یک رابط کاربری سبک، فارسی و راست‌چین برای گفتگو با مدل‌های زبانی محلی است که از طریق Ollama اجرا می‌شوند. هدف پروژه این است که برای گفتگوهای متنی و ادامه‌ی بعضی کارهای شخصی، به‌جای استفاده از ترمینال یا یک برنامه‌ی دسکتاپ سنگین، یک رابط ساده و در دسترس داشته باشید.

> **وضعیت پروژه:** نسخه‌ی اولیه‌ی آزمایشی — `v0.1.0`  
> این نسخه برای آزمایش و دریافت بازخورد منتشر می‌شود و هنوز ممکن است مشکلاتی داشته باشد.

## چرا همراه؟

قطع یا محدودشدن دسترسی به اینترنت می‌تواند ادامه‌ی کارهای روزمره را دشوار کند؛ به‌خصوص وقتی برای نوشتن، ایده‌پردازی، پرسش‌وپاسخ یا کمک در کدنویسی به یک مدل زبانی تکیه می‌کنیم. همراه تلاش می‌کند دسترسی به مدل‌های محلی را ساده‌تر کند.

**نکته:** همراه خودش مدل زبانی نیست و مدل‌ها را دانلود یا میزبانی نمی‌کند؛ رابطی برای ارتباط با Ollama است. برای استفاده‌ی بدون اینترنت، باید Ollama و مدل موردنظر از قبل نصب و دانلود شده باشند. کیفیت و سرعت پاسخ‌ها به مدل انتخاب‌شده و سخت‌افزار دستگاه بستگی دارد.

## قابلیت‌های نسخه‌ی 0.1

- رابط کاربری فارسی و راست‌چین (RTL)
- شناسایی و انتخاب مدل‌های نصب‌شده در Ollama
- نمایش تدریجی پاسخ‌ها (streaming)
- امکان توقف تولید پاسخ
- تاریخچه‌ی گفتگوها و ذخیره‌ی تنظیمات در حافظه‌ی مرورگر (`localStorage`)
- تنظیم آدرس سرویس Ollama و دستور سیستمی
- نمایش بلوک‌های کد و امکان کپی‌کردن آن‌ها
- طراحی واکنش‌گرا برای صفحه‌های کوچک‌تر

## نقاط قوت

- **سبک و مستقل:** رابط در یک فایل HTML قرار دارد و به نصب یک اپلیکیشن دسکتاپ جداگانه نیاز ندارد.
- **فارسی‌محور:** چیدمان راست‌چین و متن‌های رابط برای کاربران فارسی‌زبان طراحی شده‌اند.
- **تمرکز مشخص:** نسخه‌ی فعلی روی گفتگوی متنی تمرکز دارد و عمداً دامنه‌ی محدودی دارد.
- **اجرای محلی:** پیام‌ها از طریق سرویس Ollama محلی به مدل ارسال می‌شوند؛ همراه به‌طور پیش‌فرض از یک سرویس ابری هوش مصنوعی استفاده نمی‌کند.

## محدودیت‌ها و نقاط قابل بهبود

- نسخه‌ی `v0.1.0` اولیه است و هنوز به آزمایش روی سیستم‌ها و مرورگرهای مختلف نیاز دارد.
- برای ارتباط با مدل به نصب و اجرای Ollama و دانلود حداقل یک مدل نیاز است.
- اجرای مستقیم فایل HTML ممکن است به‌دلیل محدودیت‌های مرورگر و CORS با مشکل مواجه شود؛ روش اجرای پیشنهادی باید در محیط هدف آزمایش شود.
- این نسخه فقط از ورودی و خروجی متنی پشتیبانی می‌کند؛ قابلیت‌های صوتی، تصویری و چندرسانه‌ای ندارد.
- تاریخچه و تنظیمات در حافظه‌ی همان مرورگر ذخیره می‌شوند؛ بنابراین به‌صورت خودکار بین مرورگرها یا دستگاه‌های مختلف همگام‌سازی نمی‌شوند.
- امنیت، دسترس‌پذیری و مدیریت خطاها در این نسخه در سطح یک نمونه‌ی اولیه‌اند و نیاز به بازبینی و آزمایش بیشتر دارند.

## پیش‌نیازها

1. نصب [Ollama](https://ollama.com/download)
2. دانلود حداقل یک مدل سازگار با منابع سخت‌افزاری دستگاه
3. مرورگر مدرن

برای نمونه، می‌توانید مدلی مانند `qwen2.5:3b` را دریافت کنید (این فقط یک مثال است؛ مدل مناسب به سخت‌افزار و نیاز شما بستگی دارد):

```bash
ollama pull qwen2.5:3b
```

سپس مطمئن شوید Ollama در حال اجراست. برای بررسی مدل‌های نصب‌شده:

```bash
ollama list
```

## اجرا

1. مخزن را دانلود یا clone کنید.
2. `index.html` را باز کنید یا آن را با یک روش سرو محلی اجرا کنید.
3. مطمئن شوید Ollama فعال است و مدل موردنظرتان نصب شده.
4. وضعیت اتصال را در رابط بررسی و مدل را انتخاب کنید.

**توجه به CORS:** بسته به مرورگر و روش بازکردن فایل، ممکن است درخواست مرورگر به Ollama توسط سیاست‌های مبدأ (origin) مسدود شود. اگر اتصال برقرار نشد، ابتدا روش اجرای فایل و پیام خطای مرورگر را بررسی کنید. تنظیمات دسترسی Ollama را فقط با درک پیامدهای امنیتی تغییر دهید؛ بازکردن دسترسی برای همه‌ی مبدأها (`*`) را به‌عنوان راه‌حل پیش‌فرض توصیه نمی‌کنیم.

## حریم خصوصی

این برنامه از رابط فعلی خود برای ارسال درخواست به سرویس Ollama در آدرس تنظیم‌شده استفاده می‌کند. در تنظیم پیش‌فرض، این آدرس `http://localhost:11434` است. تاریخچه و تنظیمات گفتگو در `localStorage` مرورگر ذخیره می‌شوند. اگر آدرس سرویس را تغییر دهید، مقصد درخواست‌ها نیز تغییر می‌کند؛ پیش از استفاده، آدرس را بررسی کنید.
